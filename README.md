# 📊 HR Employee Attrition & Retention Analytics (End-to-End)

## 📌 Executive Summary
This project presents an end-to-end data analytics solution focused on understanding employee attrition drivers within an organization. Using MySQL, Python, and Power BI, the analysis transitions from raw data auditing to exploratory analysis and interactive dashboard reporting.

---

## 🛠️ Tech Stack & Tools
* **Database & Querying:** MySQL (Data extraction, department filtering, job role analysis)
* **Data Processing & EDA:** Python (Pandas, Seaborn, Matplotlib)
* **Business Intelligence & Dashboard:** Power BI (Power Query transformation, Advanced DAX modeling, Interactive dashboard visual layout)

---

## 📐 Key Insights & Metrics
* **Total Employees:** 1,000
* **Active Employees:** 762
* **Total Attrition Count:** 238
* **Overall Attrition Rate:** 23.80%
* **High-Risk Drivers:** Higher overtime usage coupled with lower job satisfaction directly impacts attrition trends across specific job roles.
